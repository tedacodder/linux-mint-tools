# Linux Mint tools

Desktop tools for Linux Mint (Cinnamon, X11).

| Project | What it does |
|---|---|
| [hotspot-manager](hotspot-manager/) | Turn Wi-Fi into a hotspot, see connected devices, and join with a QR code |
| [proxy-manager](proxy-manager/) | One switch to route your tools and system through a local proxy |
| [greeting-lock](greeting-lock/) | A lock screen that checks your real password, with a Matrix background and Snake |

Each folder has its own README with install steps.
